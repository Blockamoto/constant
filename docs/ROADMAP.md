# Constant roadmap

This is a directional roadmap, not a promise to automate everything at once.

## 0. Bootstrap

- [x] Repository and operating model
- [x] Dependency-free web shell
- [x] Public/private data boundary
- [x] Render blueprint
- [x] Validation workflow
- [ ] First scheduled GitHub capability smoke test
- [ ] Deploy dashboard to Render

## 1. Company identity

- [ ] Confirm incorporation record from authoritative source
- [ ] Store public company metadata
- [ ] Build private evidence index
- [ ] Track D-U-N-S application
- [ ] Track organisation Play Console setup
- [ ] Add product register with Proximity as the first product

## 2. Compliance memory

- [ ] Connect Companies House dates
- [ ] Add annual accounts timeline
- [ ] Add confirmation statement timeline
- [ ] Add corporation tax timeline
- [ ] Build reminders and exception reporting
- [ ] Record completion evidence without publishing private records

## 3. Finance

- [ ] Define accounting schema
- [ ] Connect transaction source
- [ ] Receipt/evidence matching
- [ ] Categorisation with human override
- [ ] Monthly close checklist
- [ ] Cash runway and commitments
- [ ] Tax/accounting export layer

## 4. Operations

- [ ] Product and service registry
- [ ] Subscription/vendor registry
- [ ] Contract and renewal calendar
- [ ] Integration health
- [ ] Decision log
- [ ] Risk register

## 5. Assurance

- [ ] Scheduled daily/weekly checks
- [ ] Drift detection
- [ ] Missing-evidence detection
- [ ] Deadline escalation
- [ ] Audit summaries
- [ ] Recovery procedures for failed automations

## Principle

Automate from a reliable record outward.

If Constant becomes impressive before it becomes trustworthy, the order is wrong.
